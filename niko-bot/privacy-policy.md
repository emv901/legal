# Niko Bot — Privacy Policy

**Effective: August 18, 2026**

This policy explains what data Niko Bot collects, how it is used, and your rights regarding that data. Niko Bot is designed to collect only the minimum data necessary to function.

## Data We Collect

| Data | Purpose | Stored |
|------|---------|--------|
| Discord User IDs | Identify users for ban/unban actions | While ban record exists |
| Discord Server (Guild) IDs | Identify which server the bot operates in | While bot is in server |
| Ban reasons and records | Provide context for moderation actions | While ban record exists |
| Command usage | Process bot commands and respond appropriately | Not stored |

## Data We Do Not Collect

- Message content (beyond bot commands)
- Voice or video data
- Direct messages
- Personal information such as email, real name, or IP address
- Data from users who do not interact with the bot

## How Data Is Used

Data is used exclusively to provide the bot's ban management functionality. We do not sell, share, or transfer your data to any third parties. Data is not used for advertising, analytics, or profiling.

## Data Storage and Security

Data is stored on secure servers and protected with reasonable technical measures. Only the bot operator has access to stored data. We retain data only for as long as necessary to provide the service.

## Data Deletion

You can request deletion of your data at any time by contacting us. When Niko Bot is removed from a server, all data associated with that server is deleted. Ban records can be removed by server administrators using the bot's commands.

## Children's Privacy

Niko Bot does not knowingly collect data from users under the age of 13 (or the minimum age required in your jurisdiction). Use of the bot requires compliance with Discord's own age requirements.

## Your Rights

You have the right to:

- Request access to any data we hold about you
- Request correction or deletion of your data
- Withdraw consent for data processing at any time
- Lodge a complaint with a data protection authority in your jurisdiction

To exercise any of these rights, contact us using the information below.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated effective date. Continued use of Niko Bot after changes are posted constitutes acceptance of the updated policy.
