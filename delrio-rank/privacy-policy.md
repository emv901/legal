# DELRIO Rank — Privacy Policy

**Effective: August 18, 2026**

This policy explains what data DELRIO Rank collects, how it is used, and your rights regarding that data. DELRIO Rank is designed to collect only the minimum data necessary to function.

## Data We Collect

| Data | Purpose | Stored |
|------|---------|--------|
| Discord User IDs | Identify players for points, ranking, and redemptions | Persistently in local data file |
| Discord Server (Guild) IDs | Separate point data per server | Persistently in local data file |
| Points and victory counts | Track player progress and ranking | Persistently in local data file |
| Redemption history | Record which rewards were redeemed, when, and who approved | Persistently in local data file |
| Command and button interactions | Process bot commands and respond appropriately | Not stored |

## Data We Do Not Collect

- Message content (beyond bot commands)
- Voice or video data
- Direct messages (the bot sends DM notifications but does not read DMs)
- Personal information such as email, real name, or IP address
- Financial or payment information
- Data from users who do not interact with the bot

## How Data Is Used

Data is used exclusively to provide the loyalty points, ranking, and redemption system. We do not sell, share, or transfer your data to any third parties. Data is not used for advertising, external analytics, or profiling.

## Data Storage and Security

Player data (points, victories, redemption history) is stored in a local JSON file on the bot's hosting server and protected with reasonable technical measures. Only the bot operator has access to stored data. Backups of ranking data are sent to a designated Discord log channel before any rank reset.

## Data Deletion

You can request deletion of your data at any time by contacting us or asking a server administrator to reset your points using the bot's admin commands. When DELRIO Rank is removed from a server, administrators should request data deletion by contacting us.

## Children's Privacy

DELRIO Rank does not knowingly collect data from users under the age of 13 (or the minimum age required in your jurisdiction). Use of the bot requires compliance with Discord's own age requirements.

## Your Rights

You have the right to:

- Request access to any data we hold about you
- Request correction or deletion of your data
- Withdraw consent for data processing at any time
- Lodge a complaint with a data protection authority in your jurisdiction

To exercise any of these rights, contact us using the information below.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated effective date. Continued use of DELRIO Rank after changes are posted constitutes acceptance of the updated policy.
