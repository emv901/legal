# DELRIO Analista — Privacy Policy

**Effective: August 18, 2026**

This policy explains what data DELRIO Analista collects, how it is used, and your rights regarding that data. DELRIO Analista is designed to collect only the minimum data necessary to function.

## Data We Collect

| Data | Purpose | Stored |
|------|---------|--------|
| Discord User IDs | Identify analysts and users in queues and sessions | In memory during bot runtime |
| Discord Server (Guild) IDs | Identify which server the bot operates in | In memory during bot runtime |
| Voice channel IDs | Track which channels have active analysis sessions | In memory during bot runtime |
| Queue position and status | Manage analyst queues for mobile and emulator | In memory during bot runtime |
| Weekly analysis counts | Generate analyst performance statistics | In memory, reset weekly |
| Command and button interactions | Process bot commands and respond appropriately | Not stored |

## Data We Do Not Collect

- Message content (beyond bot commands)
- Voice or video data from analysis sessions
- Direct messages
- Personal information such as email, real name, or IP address
- Payment details or financial information
- Data from users who do not interact with the bot

## How Data Is Used

Data is used exclusively to provide analyst queue management and session tracking. We do not sell, share, or transfer your data to any third parties. Data is not used for advertising, analytics beyond in-bot statistics, or profiling.

## Data Storage and Retention

DELRIO Analista stores operational data in memory only. This means all queue data, active sessions, and weekly statistics are automatically cleared when the bot restarts. No data is written to permanent storage or external databases.

## Data Deletion

Since data is stored only in memory, it is automatically deleted on bot restart. You can also leave a queue at any time using the bot's commands, which removes your data from that queue immediately.

## Children's Privacy

DELRIO Analista does not knowingly collect data from users under the age of 13 (or the minimum age required in your jurisdiction). Use of the bot requires compliance with Discord's own age requirements.

## Your Rights

You have the right to:

- Request information about any data we hold about you
- Request removal of your data from active queues and sessions
- Withdraw consent for data processing at any time
- Lodge a complaint with a data protection authority in your jurisdiction

To exercise any of these rights, contact us using the information below.
